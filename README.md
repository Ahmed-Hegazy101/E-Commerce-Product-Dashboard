# 🛒 CommerceHub - E-Commerce Admin Dashboard (SPA)

A modern, high-performance, and fully interactive **Single Page Application (SPA)** E-Commerce Admin Dashboard built with pure **Vanilla JavaScript**, HTML5, and CSS3.

Designed with a desktop-first approach, CommerceHub delivers a seamless administrative interface for managing products, tracking inventory metrics, and viewing real-time order insights—without relying on external heavy JavaScript frameworks.

---

## 🌟 Key Features

- **⚡ Single Page Architecture (SPA):** Instant, smooth view switching between Dashboard, Products Management, Orders, and Settings without full page reloads.
- **📊 Dynamic Metrics & Analytics:** Real-time summary cards displaying total products, inventory status, low stock alerts, and revenue trends.
- **📦 Full CRUD Operations:** Dynamic product management featuring custom modal dialogs for adding and editing catalog items.
- **🔍 Real-Time Live Search & Filtering:** Instant client-side search filtering across product catalogs and dynamic data tables.
- **💾 LocalStorage Data Persistence:** Full state persistence allowing created/edited products and settings to stay intact across browser sessions.
- **🎨 Custom Modern UI/UX:** Built with modern CSS Grid & Flexbox, smooth transitions, custom modal overlays, and inline SVG branding.
- **🇪🇬 Egyptian Market Localization:** Pre-configured with realistic local business mock data, currency formats (EGP / ج.م), and standardized profile credentials.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3 (Custom CSS Variables, Flexbox, CSS Grid)
- **Scripting:** Pure Vanilla JavaScript (ES6+ Modules, DOM Manipulation, Event Delegation)
- **State & Storage:** Web Storage API (`localStorage`)
- **Icons & Visuals:** Embedded Inline SVG Assets
- **Dependencies:** **Zero External Frameworks** (No React, Vue, jQuery, or Bootstrap)
